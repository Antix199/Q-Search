# Q-Search

Este es el repositorio de documentos de Q-Search, un proyecto que consiste en la implementación y comparación de dos enfoques para resolver el problema de búsqueda en un espacio no estructurado:

1. Búsqueda clásica exhaustiva, que recorre secuencialmente el espacio de soluciones.
2. Algoritmo de Grover, que utiliza principios de computación cuántica para reducir el número de iteraciones necesarias.

Este repositorio considera los documentos obtenidos de las ejecuciones desde el segundo avance en adelante, debido a la fecha de su creación.
Sin embargo, se adjunta también el informe correspondiente al primer avance.

Para ver los infromes de avance dirigirse a la carpeta [Informes de avance]([Informes de avance/](https://github.com/Antix199/Q-Search/tree/dca5c4d973967f72bbdb0bf7b07d3b466a2c4d8f/Informes%20de%20avance))
