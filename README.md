# Q-Search

Este es el repositorio de documentos de Q-Search, un proyecto que consiste en la implementación y comparación de dos enfoques para resolver el problema de búsqueda en un espacio no estructurado:

1. Búsqueda clásica exhaustiva, que recorre secuencialmente el espacio de soluciones.
2. Algoritmo de Grover, que utiliza principios de computación cuántica para reducir el número de iteraciones necesarias.
