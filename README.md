# Q-Search

Este repositorio contiene la documentación de **Q-Search**, un proyecto enfocado en la implementación y comparación de dos enfoques para resolver el problema de búsqueda en un espacio no estructurado:

1. **Búsqueda clásica exhaustiva**, que recorre secuencialmente el espacio de soluciones.
2. **Algoritmo de Grover**, que utiliza principios de computación cuántica para reducir el número de iteraciones necesarias.

Este repositorio incluye la documentación generada desde el segundo avance en adelante, debido a la fecha de creación del repositorio. No obstante, también se adjunta el informe correspondiente al primer avance.
